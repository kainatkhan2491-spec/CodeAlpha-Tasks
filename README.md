# CodeAlpha Frontend Development Projects

Two projects built with HTML, CSS and JavaScript as part of the **CodeAlpha Frontend Development Internship**.

| Task | Project | Folder |
|------|---------|--------|
| Task 1 | Image Gallery | `ImageGallery/` |
| Task 2 | Calculator | `Calculator/` |

---

## 1. Image Gallery

A responsive image gallery with a lightbox.

**Features**
- Responsive grid layout for mobile, tablet and desktop
- Lightbox view with Next / Previous buttons
- Keyboard support: `←` `→` to navigate, `Esc` to close
- Category filters (All, Nature, City, Animals)
- Hover zoom effect and smooth transitions

**Customize:** edit the `photos` list at the top of `ImageGallery/script.js` to use your own images.

---

## 2. Calculator

A simple calculator with a clean interface.

**Features**
- Addition (+), subtraction (−), multiplication (×) and division (÷)
- Real-time display of the current number and expression
- AC (clear), ⌫ (delete) and % (percentage) buttons, decimal support
- Error handling for division by zero
- Keyboard support: `0-9`, `.`, `+ - * /`, `Enter`, `Backspace`, `Esc`

---

## Technologies Used
- HTML5
- CSS3 (Grid, transitions, animations)
- JavaScript (DOM manipulation, event handling)

## How to Run
1. Download or clone this repository.
2. Open the project folder you want (`ImageGallery` or `Calculator`).
3. Open its `index.html` in your browser. Keep `index.html`, `style.css` and `script.js` together in the same folder.

(The gallery needs internet to load the sample images.)
